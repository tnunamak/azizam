## Design Context

This file is the portable visual direction for the gateway UI. The files under
`tmp/designs/` are local deployment evidence used to calibrate visual grammar;
they are not a portable product requirement and must not be treated as a
required source asset in another checkout.

### Users
The gateway is for self-hosted AI operators and their trusted users: r/selfhosted, r/LocalLLaMA, r/stablediffusion-style people who run local/cloud AI services, manage household/friend/agent access, and need to understand what is available, constrained, or down without reading logs first. Normal users need clear access and key management; admins need a compact control room for services, profiles, apps, users, audit, and settings.

### Brand Personality
Calm, technical, and accountable. The interface should feel like a high-contrast operations console for a capable local system, not a SaaS landing page, not a marketing funnel, and not a toy dashboard.

### Aesthetic Direction
Dark, dense, and polished with Vivid Fish identity: deep-water surfaces, bright but sparse cyan/green status accents, elevated panels, hairline dividers, compact top status/account clusters, and mobile bottom navigation. Designer screenshots in `tmp/designs/` are authoritative for visual grammar; marketing slogans, pricing, customer language, and generic "build in minutes" positioning are not.

### Design Principles
- Make the product state visible: services, access, keys, queues, and recent changes should be scannable at a glance.
- Keep complexity essential: no dead affordances, no fake charts, no decorative metrics, and no service-specific wizards in a service-unopinionated product.
- Put shared visual language in `@vivid-fish/brand`; React components adapt those primitives to app data rather than inventing one-off Tailwind styling.
- Optimize for repeated operator use: dense rows, restrained copy, strong contrast, predictable navigation, real empty/loading/error states.
- Mobile must be a first-class control surface with bottom navigation and no horizontal overflow, not a shrunken desktop sidebar.
