## What people pushing the edge are doing (and what we can borrow)

## What you shipped is not the brand. It's `firehose-vivid-fish.css` with a `package.json` taped to it.

Your own README says it: "Tokens come from … the in-production status page at `openai-proxy/firehose-vivid-fish.css`. They are kept in sync by editing this package." That is a CSS extraction, not a design system. The migration section at the bottom of the README — *3 steps to rename classes on the existing status page* — is the actual scope of this work. Calling it `@vivid-fish/brand` and bumping `0.1.0` doesn't make it one.

## Specific charges

### 1. You ignored the four principles. All four.

- **"Calm beats loud."** You shipped `--dive-biolum: #2DE0E6` (radioactive cyan), `--dive-coral: #FF4B8C` (shocking pink), and a permanent text-shadow glow keyframe. The system warned against this on the cover slide. Principle 01.
- **"Display, not italic."** Your type scale tops out at `--vf-text-xl: 18px`. There is no display token. Newsreader is loaded from Google Fonts and never used in `components.css`. So you paid the network cost without getting the typeface. Worst of both worlds.
- **"Caustic, not gravity."** I see `--vf-shadow-glow-biolum-strong: 0 0 24px rgba(45,224,230,0.50)` and `box-shadow: 0 0 24px` in `biolum-glow`. That's a 360° glow. Caustics are *directional* — light from above. You shipped a UFO.
- **"One signature move."** You sprinkled biolum glow on banners, badges, code, mono cells, group labels, alert borders, progress bars, and details bodies. That's not a signature, that's a tic.

### 2. The headline pulse is a footgun.

```css
.vf-banner-ok > h1,
.vf-banner-ok .vf-banner-title {
  animation: biolum-pulse 4s ease-in-out infinite;
}
```

You attached a 4-second infinite text-shadow + opacity animation to **any `h1` inside any OK banner, anywhere, forever, with no opt-out**. "Healthy" should feel still. Yours twitches every four seconds. Users with vestibular disorders or `prefers-reduced-motion` get nothing. There's no `@media (prefers-reduced-motion: reduce)` block in the entire package. That's not a stylistic miss, that's a WCAG miss.

### 3. The naming is four prefixes pretending to be a system.

You have:
- `--dive-*` for raw colors,
- `--vf-*` for semantic aliases,
- `--color-dive-*` (a third copy of the same hex values) for Tailwind utilities in `@theme`,
- `vf-*` for component classes,
