## Verified findings
- tests/test_route_policy_inventory.py:875–883 prints coverage gaps/not-exercised rows but fails only VIOLATION. HTTP 400/422, no-backend >=500, member-session 401 and missing category proof can therefore avoid the report's failure gate.
- The HTTP category inventory adds two synthetic NOT RUN rows (“paid chat models”, “paid decision paths”) claiming out-of-base coverage. A strict report must expose these as unresolved coverage, not silently drop them or convert them to passes.
- _category_oracle demotes rows without a category refusal to “not exercised”, including some valid discovery/metadata cases. Separate explicit, independently asserted non-dispatch/discovery contracts from execution-denial proof; do not require a category refusal for an allowed metadata contract, nor use a blanket GET exemption.
- _decoy_oracle currently has a broad GET-200/no-calls metadata classification, and special status-probe allowances including HTTP/network tripwires. Narrowing these requires an explicit route contract; never let them erase dispatch evidence. Existing oracle self-tests already preserve multiple backend/dispatch violations.
- tests/test_runtime_route_policy.py:493 and :620 have respectively two and five subcases that only assert 200 from identical mocked responses. Wrong handler, missing await, duplicate await and wrong arguments may remain green.
- Catchall tests already use real SQLite credentials and receipts and already contain strong no-dispatch oracles. Keep all seven query variants, both identities, all methods/paths, authenticating unsupported path-token controls, unauthenticated controls, canonical native denial, receipt deltas, and token non-disclosure.
- Category enforcement already uses real CategoryStore SQLite, including corrupt/lost store and activation/cache refresh. The kernel suite is deliberately pure, not a fake-store suite.
- No positive-duration sleeps occur in the scoped files. request_source has two asyncio.sleep(0) scheduler yields that create concurrency; these are not elapsed-time delays and should not be removed as a speed optimization.
