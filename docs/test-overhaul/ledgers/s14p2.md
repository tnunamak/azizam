## Tiers and table semantics
F = browser functional/HTTP-contract test (route stubs appropriate for presentation/transport faults).
G = browser geometry. A = axe serious/critical. V = compared visual golden.
E = browser + real isolated gateway/SQLite persistence/security integration.
SAME means the exact old file::case ID in that row remains its new home; existing body assertions remain, with screenshot comparisons added, except the explicitly described special rewrites.
For split matrices, F case IDs and G/A/V case IDs below are exact proposed names within the SAME file. Functional repetitions merge only; every original state/theme/width geometry and axe checkpoint has a survivor. G still checks readiness and any viewport-conditional DOM/interaction branch. No state is assumed equivalent to seeded.
P: expected old AND new mutant kill by the retained assertion (source-grounded prediction, execution UNVERIFIED).
S: expected only strengthened new oracle kills the specified mutant; old may incidentally fail a different assertion but must not receive kill credit without evidence.
All row failures are intended diagnostic/assertion messages, NOT observed logs. Invariant keys resolve to the full definitions below. Rows use complete concrete old titles, so parameters are not hidden behind a wildcard. Repeating an old ID only occurs when a split needs multiple destinations.

## Risks and stop conditions
- Scope prevents production review and exact mutant diffs; these are explicit gaps, not an invitation to expand reads or launch execution.
- Matrix members are not interchangeable: public OIDC differs, state-specific DOM differs, owner/member rights differ, viewport-specific facts/tables/touch targets differ. Pairwise selection alone can miss a single-route390 or one-theme defect.
- Retaining parity G/A tuples preserves guard coverage but limits expected speedup; moving assertions to another test may increase case count/setup. Assertion count or declarations removed is not wall-time evidence.
- Screenshot baselines need review, deterministic fixtures and exact browser/OS/font settings. Exported screenshots were artifacts, not an oracle. Common colors may pass contrast while still being wrong; class persistence cannot replace token comparison.
- Broad route stubs can hide persistence/concurrency errors. Mocked revoked-key/paid denial is not security evidence. Existing real journeys are non-negotiable anchors; parallel shared DB mutation and cleanup failures can contaminate results.
- Promise release/route.fulfill/network response is not necessarily UI consumption; an immediate negative check can pass before a stale response mutates UI. No replacement sleep should masquerade as causality.
- Multipart scalar pairing and duplicate cardinality must be parsed using the actual boundary; splitting arbitrary UTF-8 strings corrupts binary and permits false positives. Do not overconstrain field ordering unless actual API semantics require it; compare paired multimap, not random boundary text.
- Composed ready/idle fixtures cannot prove runnability as written. Valid declared contract and result path are required before click coverage; do not silently use an unrelated generic workflow to make the test pass.
- If-Match source contract is unread; current synthetic ETags are insufficient to infer production method/status/sequence. No old kill credit claimed.
- Receipt-retention raw CLI SQL and runtime-discovered DB are test-owned only but isolation/clock discipline matters. Browser fixed time alone does not freeze SQLite/backend expiry; use shared test clock.
- Sweep imports/runtime environment determine unknown expansions and target may be fixtures vs copy. Do not claim literal378 is main-config count or that diagnostic marked-up JPEGs meet visual golden requirements. L89 remaining300ms sleep is identified and not silently removed.
- Household manifest contains runtime secrets: no manifest read or real credential handling occurred; keep secrets out of snapshots, traces and reports. Source test fixture strings are illustrative and not live credentials.
- Workflow sheet screenshot name collision and tour operator-home exports can overwrite evidence. Names must encode state/open-disclosure/role/theme/width, and outputs stay test-owned.
- Third-party fixture imports and Playwright config were not read; syntax, helper availability, baseline generation, test collection and all run/check results remain UNVERIFIED.
