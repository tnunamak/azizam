Each row is an old test declaration or explicit parameter-value case that this plan changes, moves, or affects through home_case replacement. File aliases are expanded below. No existing test is deleted in this bounded plan. Assertions mentioned together in a row are conjunctive: splitting a case never permits dropping its subsidiary assertions.
P = preservation candidate: the old assertion is expected by inspection to fail for the named behavior mutant, and the new test must fail too. This is a prediction; both executions are UNVERIFIED.
S = strengthening: old test does not establish the named behavior, or may survive the mutant; new test must fail. A row can have both P and S obligations.
Expected failures are prescribed assertion messages for the rewritten test, not observed output.
Bracket values denote exact source parameter values in declaration order, not unverified pytest-generated display IDs.
U = Python pure/unit; I = Python ASGI/SQLite/file integration; J = required JS/jsdom; B = required real-browser layout/integration.
