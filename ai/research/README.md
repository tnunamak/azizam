# Research Notes

This directory captures bounded research that supports shipped documentation in
this worktree.

Entries should record:

- the question being answered;
- local corpus checked before web research;
- every primary source read;
- short source excerpts, kept within copyright limits;
- findings, caveats, negative results, and dead ends;
- the document or decision that used the research.

Do not mutate the external research corpus from this worktree. If a later lane
has write access to the shared corpus, it can promote these notes there.
