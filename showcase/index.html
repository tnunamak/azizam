How it fits together

You run the gateway

Install Azizam on a computer you control. Add the engines you run, and paid providers only if you want them. Engines and model names are settings, not code, so you can swap them when better ones come out.

People get their own access

Invite family or friends with a link. Each person gets their own key and an access plan that sets which models they can use and how much they can spend. Their requests, creations and receipts are tied to their own apps.

Apps and agents connect

Point an OpenAI-compatible app at /openai/v1 with its key. Anthropic and Ollama clients have their own routes, and agents can use the MCP server at /mcp. Home in the gateway has connection recipes.

Know where requests go

  • Local engines. A request to an engine you run goes from the gateway to that engine, on hardware you control.
  • Paid providers. A request to a paid model goes to that provider, under its terms, and only when the access plan allows paid use. If a local engine is down, the request does not move to a paid provider unless you set that up.
  • Keys. Every request needs a key by default, on your home network too. Give each app its own key so you can revoke one without breaking the others. Keep admin keys out of apps.
  • Download links. A signed link to a creation works for anyone who has the full link until it expires. Share it as carefully as a key.

Get started

You need Docker with Compose, and an engine that serves an OpenAI-compatible chat API with a model already loaded. Azizam connects to engines; it does not download models.

  1. Start the gateway

    In a copy of the repository, run:

    docker compose up -d

    The first build takes the longest. Then open http://127.0.0.1:5000/setup on the same computer.

  2. Add your engine and a key

    Create the owner account. In Gateway → Engines, add your engine's address and map a model name, such as my-model, to the engine's own model. On Home, create a key for your app and save it; it is shown once.

  3. Send the first request

    In your app, set the base URL to http://127.0.0.1:5000/openai/v1, paste the key and choose my-model. Send a short message. A reply in your app means it works. Then invite people from Gateway → People.

Read the setup guide for other ports and engines on the same computer, then Security before other devices connect.

Before you rely on it

  • What you can make depends on the engines and model files you connect. The examples above show what this gateway did when they were recorded.
  • A route that accepts a vendor's API format does not mean every feature of that API works. Each API page lists what works and what does not.
  • Paid use is estimated and reserved before a request, then settled after. A final cost can stay unknown until it is reconciled, and requests already running can take spend past a cap. Set a credit limit with the provider too.
  • You run the computer: updates, backups and HTTPS for access from other devices are yours to set up.
