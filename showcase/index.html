How it works

Start in a few minutes

docker compose up -d

  1. Open http://127.0.0.1:5000/setup and create the owner account.
  2. Add your engine's address and give its model a name.
  3. Create a key, point your app at /openai/v1, and send a message.

Read the setup guide

Before you rely on it

  • You choose the engines and model files. Azizam connects to them; it does not download models.
  • Compatibility is per route. Each API page lists the features that work and their limits.
  • Paid spend is estimated, reserved, then settled; final cost may remain unknown. Running requests can pass a cap; set a provider credit limit too.
  • You run the computer, including updates, backups and HTTPS for access from other devices.
