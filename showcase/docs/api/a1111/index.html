Build with the API

A1111-compatible API

Set your client's URL to the gateway address, $AZIZAM_BASE_URL. The routes are under /sdapi/v1.

On this page
  • Choose a model
  • Text to image with curl
  • Text to image with Python
  • Routes
  • Limits

The gateway turns text-to-image requests into its own image workflows, and waits for the result. The model list comes from the gateway's image models and workflows.

Send your app key as a bearer token or as x-api-key. For a client that uses Basic authentication, use the app key as the password.

First follow Set up your environment. Run the model-list request below, then export AZIZAM_IMAGE_MODEL with an exact title from that response before running either generation example.

Choose a model #

Shell
curl --fail-with-body -sS "$AZIZAM_BASE_URL/sdapi/v1/sd-models" \
  -H "Authorization: Bearer $AZIZAM_API_KEY"

Replace the example value with a title from the response, then run:

Shell
export AZIZAM_IMAGE_MODEL='REPLACE_WITH_MODEL_TITLE'

Text to image with curl #

The response is JSON. Its images list holds base64 image data. This example saves the response to a file.

Shell
python3 - <<'PY' | curl --fail-with-body -sS "$AZIZAM_BASE_URL/sdapi/v1/txt2img" -H "Authorization: Bearer $AZIZAM_API_KEY" -H 'Content-Type: application/json' --output txt2img.json --data-binary @-
import json, os
print(json.dumps({"prompt": "A blue ceramic bowl on a plain table.", "override_settings": {"sd_model_checkpoint": os.environ["AZIZAM_IMAGE_MODEL"]}}))
PY

Text to image with Python #

This example uses only the Python standard library. It saves the first picture.

Python
import base64
import json
import os
from urllib.request import Request, urlopen

body = {
    "prompt": "A blue ceramic bowl on a plain table.",
    "override_settings": {"sd_model_checkpoint": os.environ["AZIZAM_IMAGE_MODEL"]},
}
request = Request(
    os.environ["AZIZAM_BASE_URL"].rstrip("/") + "/sdapi/v1/txt2img",
    data=json.dumps(body).encode(),
    headers={
        "Authorization": "Bearer " + os.environ["AZIZAM_API_KEY"],
        "Content-Type": "application/json",
    },
)
with urlopen(request, timeout=660) as response:
    result = json.load(response)
with open("picture", "wb") as f:
    f.write(base64.b64decode(result["images"][0]))

Check the file type before you add an extension.

Routes #

txt2img, options, sd-models, samplers, schedulers, upscalers, latent-upscale-modes, sd-vae, progress and interrupt. A route that lists choices does not mean the gateway supports those features.

The selected model is kept per app until the gateway restarts. An interrupt affects only that app's work.

Limits #

  • Hires fix, face restoration, scripts, styles, refiners, variation seeds and LoRA prompt tags return HTTP 422.
  • img2img, extras upscaling, interrogate and png-info return HTTP 501.
  • Settings the gateway ignores are named in the x-azizam-ignored-params header. They can include the negative prompt, sampler, scheduler, cfg_scale and clip_skip.
  • A VAE choice is dropped. The list of VAEs is empty.
  • Steps and guidance can be clamped to the workflow's range. An invalid size, tiling, seed resizing, an unsupported override_settings key, or more than 10 pictures in one request returns HTTP 422.
  • A request that takes more than ten minutes returns HTTP 504.

These routes are not in the gateway's OpenAPI document.
