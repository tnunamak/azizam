Use a gateway

Usage and receipts

On this page
  • Check this month
  • Open a receipt
  • Check coverage
  • When usage does not load

Usage shows this month's requests, spend, creations and failures.

Check this month #

Open Usage. The tiles show Requests, Spend, Media made and Failed. The daily and model sections give more detail when records are available.

  • Cost not recorded means that the amount is unknown. It does not mean that the request was free.
  • No provider charge on a receipt means that its record says the request stayed on the gateway's own engines.

Open a receipt #

A receipt shows what happened to one request: its task, model, source, time, duration and outcome, when they were recorded.

  1. Select View recent requests.
  2. Select a request to open its receipt.

You can also open a receipt from Try or Library when a receipt link is shown.

Check coverage #

Open Receipt coverage, when it is shown, to read how much history the totals include. The totals may not include every past request.

When usage does not load #

Select Retry usage. Until a refresh succeeds, the totals on screen are the last ones that loaded.

If a receipt link says that the request wasn't found for your account, the receipt belongs to someone else or was deleted.

Read Receipts and usage to learn how the totals are counted.
