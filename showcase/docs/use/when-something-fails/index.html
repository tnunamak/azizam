When something fails

Read the message on screen first. It names the problem and, in most cases, the next step.

On this page
  • The model or workflow list does not load
  • A request fails
  • The connection drops while something is made
  • A workflow is still running
  • Recording fails
  • A download fails
  • A key change fails
  • Usage does not refresh

The model or workflow list does not load #

Select Retry model catalog or Retry workflow catalog. If the page says that no options are listed, nothing is available for that choice. Ask the owner.

A request fails #

Read the message in Try. Select Edit and run again when it is offered. Your values stay in the form. Check them, then select Run. The button does not repeat the request on its own.

The connection drops while something is made #

The gateway may still be making it. Select Open Library when it is offered, and look for the finished creation before you start another run. For other requests, reconnect and use Edit and run again.

A workflow is still running #

Select Check job when it is shown. This checks for the output of the job that is already running.

Recording fails #

Check that the browser can use the microphone. Then select Record again, or choose an Audio file.

A download fails #

Select Download again. If Library could not prepare the file, open the creation and try again.

A key change fails #

  • If the app exists but its key was not created, select Retry key creation.
  • If a replacement key is saved but the old keys still work, retry revoking them. Rotation is not finished while that warning is shown.

Usage does not refresh #

Select Retry usage. Until it succeeds, the totals on screen are old.

If a problem continues, tell the owner what you did and what the message said. Do not send your key, a download link or private media.
