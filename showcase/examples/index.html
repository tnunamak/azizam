About the examples

The capability list comes from this gateway's discovery routes: /gateway/v1/capabilities, /gateway/v1/workflows, /gateway/v1/aliases and /openapi.json. Recorded examples were made with a script and stored on this gateway; a live run is a new request and can differ.
