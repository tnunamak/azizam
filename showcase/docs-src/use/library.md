# Library

**Library** holds the pictures, videos and audio you made.

## Find a creation

1. Open **Library**.
2. Enter text in **Search your creations**. On a phone, select the search icon first.
3. Choose All, Images, Video or Audio to narrow the list. Select Filters to choose a Model or a Date: Any time, Last 7 days, Last 30 days or Last 90 days.

If nothing matches, select **Clear filters**. A creation without a saved prompt is named by its type and time.

## Open a creation

Select a creation to open it. Use **Previous creation** and **Next creation** to move through the list, and **Close** to return.

When a saved prompt is available, you can read it and select **Copy prompt**. When a receipt link is shown, select it to open the receipt for the request.

## Download a creation

1. Open the creation.
2. Select **Download**, and wait while the file is prepared.

Some creations also offer **Download with details** in the actions menu. That file includes the prompt and the workflow text. Think about who will see it before you pass it on. A downloaded copy cannot be recalled.

## Delete a creation

1. Open the creation, then open its actions menu.
2. Select **Delete**, if it is shown.
3. Read the confirmation, then select **Delete**.

This removes the creation from your Library. Copies you downloaded stay where they are. See [Library and retention](../concepts/library-and-retention.md) for what deletion does on the gateway.

## When a file is unavailable

Library lists unavailable files separately. Select Show them to see these items, and Refresh library to check again. The message distinguishes files that are unavailable from files that are no longer stored. An unavailable creation can still have a receipt.
