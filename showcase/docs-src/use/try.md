# Try

Use **Try** to run a single request in the browser. Each task shows the request it sends, so you can repeat it from your own app later.

## Choose a task and a model

1. Open **Try** and select the task you want. On a phone, swipe the row of tasks to see more.
2. Open **Model name** and choose a model.
3. Read any availability message before you run the task.

Some models show a paid label. A paid model sends your request to an outside provider.

## Send a message

1. Choose the chat task.
2. Enter your message in **Prompt**.
3. Select **Run**.

The reply appears in the result area. Each run sends only the message in the box. Earlier replies are not sent as conversation history.

## Make a picture

1. Choose the picture task and a model.
2. Describe the picture in **Prompt**.
3. Select **Run**.

While the picture is made, Try says that you can switch to another app and it keeps going.

To start from a picture you already have, for example to edit or upscale it, look under **Workflow**.

## Make speech

1. Choose the speech task and a model.
2. Enter the words in **Prompt**.
3. Choose a voice, if the model offers a choice.
4. Select **Run**.

Play the result in the audio player, or use the download link when one is shown.

## Turn audio into text

1. Choose the transcription task and a model.
2. Select an **Audio file**, or select **Record**. Select **Stop** when you finish recording.
3. Select **Run**.

The text appears in the result area. If recording does not start, check that the browser can use the microphone, or choose a file.

## Run a workflow

A workflow is a named task, such as making a video or a piece of music. The gateway lists only the workflows the owner set up.

1. Choose **Workflow**, then choose a workflow under **Model name**.
2. Fill in the fields it shows, and add any files it asks for.
3. Select **Run**.

If a required input is missing, the form points to it. If the result shows **Check job**, select it to check for the output. When the output is ready, use the player or the download link.

## Don't keep a prompt

Before you make a picture, speech or a workflow result, look above **Run** for **Don’t keep this prompt**. Turn it on when you do not want the prompt kept with the creation.

- The creation still goes to Library. The result can show **Prompt not kept**.
- Try remembers the switch for this browser session, when the browser allows it. Check it before later runs.
- Picture and workflow jobs with a prompt that is not kept cannot resume after a gateway restart.

If prompt keeping is already off, the row says **Prompts aren’t kept** instead. If you turned it off yourself, **Change** opens **Your settings**. If the owner turned it off for everyone, the row says so.

Read [Prompt saving](../concepts/prompt-saving.md) to learn what is kept and for how long.
