# Library and retention

Library shows the pictures, videos and audio made through the gateway. It builds each entry from jobs, files, receipts and app ownership.

An entry can show its model, workflow, time, size, source and how long it took, when those facts were recorded. An entry can stay in the list after its file is gone. An entry is not a backup of its file.

## What the gateway keeps

| Data | How long |
| --- | --- |
| Creations, jobs, job events and saved conversations | No automatic time limit. |
| Receipts | No time limit by default. The owner can set a limit, with a preview of what will be deleted. |
| Saved prompts | Depends on prompt settings. See [Prompt saving](prompt-saving.md). |
| Signed download links | Expire. The file stays. |

A saved prompt can expire or be erased without deleting the creation.

## What deleting a creation does

Deleting from Library works only on your own creations, for the owner too. It removes your saved prompt for that creation and records the deletion.

It also deletes the file, unless another person or app shares the same file. Then the gateway keeps the file for them. Removing a creation from your Library does not always erase every copy.

Retention settings are not a backup plan. Disk space, engines and backups need their own care. See [Upgrade and back up](../operate/upgrade-and-backup.md).
